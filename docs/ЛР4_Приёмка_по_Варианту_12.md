### 8. Компакция, число файлов и средний размер по партициям — ✅ исторический эксперимент
По NOTES.md до обслуживания 20 активных data-файлов, 764703868 байт; за 27.10 было 5 файлов / 3459547 байт. Вызов rewrite_data_files переписал 5 файлов в 1 за 27.10, размер нового файла 2571537 байт, всего осталось 16 активных файлов. Число строк неизменно. Объяснение: компакция по умолчанию выбирает группы достаточно мелких файлов, удовлетворяющие критериям переписи; в предыдущем опыте таким набором оказалась партиция последних суток. Это **наблюдение одного прогона**, не общее свойство Iceberg.

Посмотреть текущие размеры без изменений:
~~~bash
docker compose run --rm -T spark /opt/spark/bin/spark-sql -e "SELECT partition, count(*) files, avg(file_size_in_bytes) avg_bytes FROM lake.clean.events.files GROUP BY partition ORDER BY partition"
~~~

### 9. Expire snapshots и число ВСЕХ объектов в bucket — ◐

### 10. Добавление поля v2 без перезаписи — ✅ исторический опыт
Выполнен ALTER TABLE lake.clean.events ADD COLUMN NUMTRADES BIGINT. По NOTES.md до и после — 16 активных файлов / 763815858 байт; COUNT(NUMTRADES)=0, COUNT(*)=7814151. Новое поле nullable; в старых Parquet его нет, поэтому NULL. После перезагрузки 03.11 нужен новый SELECT, если преподаватель запросит *текущее* состояние:

~~~bash

docker compose run --rm -T spark /opt/spark/bin/spark-sql -e "SELECT count(*), count(NUMTRADES) FROM lake.clean.events"
~~~
