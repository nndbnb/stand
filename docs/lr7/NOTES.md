## ЛР7. Пакетная обработка TQBR

Окно чтения — от полуночи D включительно до полуночи D+1 исключительно в UTC. В Iceberg исходные события разбиты по day(event_time). В formatted-плане BatchScan нужно найти обе границы event_time у источника. Exchange с hashpartitioning собирает записи одной группы на одном исполнителе. Частичный подсчёт различных ключей может добавить обмен по ключам часа, SECID и BOARDID; окончательная группировка оставляет час и SECID. Запись Iceberg может добавить собственный обмен. Точные ключи и номера стадий берутся из конкретного запуска. Input в Stages — байты, зарегистрированные источником; нулевой счётчик сам по себе не измеряет размер файлов. В SQL → Scan смотрим также метрики файлов Iceberg.

**Перекос при соединении.** Первый запрос сортирует и соединяет по SECID. Во втором Spark рассылает небольшую таблицу частот тикеров исполнителям. Оба читают один кэшированный набор. Время относится к завершающей стадии соединения. Рассылка имеет отдельную стоимость. Один лидер по числу записей ещё не устанавливает причину долгой задачи.
